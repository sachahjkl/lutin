Lutin

An AI coding agent for your Nintendo DSi. Ask for a game, run it, then change the rules.

Download LutinUser guide

“Make me a platformer.”

Lutin writes Lua files on your SD card, runs them, and reads the errors. You supply the ideas and the button presses.

Sprites, animations, music, tiny games. Saved programs also run offline.

This recording replays DeepSeek responses in melonDS. File and runtime tools execute in the ROM.

Download the latest releaseInstallation guide

The SD ZIP includes the ROM, model catalog, certificates, and starter projects. Keep your existing projects and settings when updating.

  1. Set up a homebrew launcher with the DSi CFW Guide.
  2. Copy the release files to a FAT32 SD card.
  3. Add your OpenCode Go API key and configure Wi-Fi.
  4. Launch Lutin in DSi mode.

No API key yet? Run the bundled starter program offline.
