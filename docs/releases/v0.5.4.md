# Lutin v0.5.4

## Connection diagnostics

Transport errors now retain the libcurl code, operating-system error, and resolved destination IP.
Read the complete result in **START → Diagnostics → Network**.
The compact status area displays only the first two lines.

The emulator socket check initializes the real DS network stack.
It repeats connection setup and cleanup with injected connection-refused and network-unreachable errors.
This checks resource cleanup and error reporting without contacting a provider.

This release does not claim to fix the reported intermittent connection failure.
A cancelled DNS request can still leave the system resolver running.
If subsequent requests keep reporting **DNS worker unavailable**, restart Lutin.

## Upgrade

From v0.5.0 or later, replace the ROM and retain your SD data.
From an earlier version, also install `/lutin/models.json` from the SD ZIP.
