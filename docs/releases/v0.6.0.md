# Lutin v0.6.0

## Create, test, and inspect

- Run seeded tests with fixed frame steps and injected buttons or touch input.
- Inspect creation-defined state, Lua memory, frame timings, errors, and budget failures.
- Send immutable PNG captures to image-capable models through either supported transport.
- Save source checkpoints and restore them after failed edits or interrupted restoration.
- Reuse tilemaps, camera offsets, animation, modules, text measurement, touch buttons, and project save data.
- Render small flat-color 3D meshes with clipping and depth testing on the CPU framebuffer.

The keyboard map no longer overlaps its graphics allocation.
Chat and creation text support Latin-1 accents, French ligatures, and common combining accents.

## Verification

The release includes regression tests for the defects found during an independent subagent review.
Automated checks cover serialization limits, save-data budgets, checkpoint recovery, input, rendering, image requests, and keyboard VRAM.
The 2D and 3D emulator checks replay recorded model responses while executing the real agent, tools, and Lua runtime.
The emulator displays `REPLAY`; these recordings are not live console inference.
The release assets include separate 2D and 3D MP4 recordings and checksums.

3D uses software rendering, not the DSi hardware 3D engine.
Host and DS-mode emulator results do not establish physical-DSi frame rates or network reliability.

## Upgrade

Replace `/roms/nds/lutin.nds` and update `/lutin/models.json` from the SD ZIP.
The catalog now declares image-input support. Retain personal model overrides and project data.
See [Creation tools](https://github.com/sachahjkl/lutin/blob/main/docs/creation-tools.md) and [Verification evidence](https://github.com/sachahjkl/lutin/blob/main/docs/verification.md) for contracts and evidence.
