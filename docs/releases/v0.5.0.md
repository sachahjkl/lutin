# Lutin v0.5.0

## Changes

- Load providers and models from `/lutin/models.json` instead of a compiled list.
- Preserve personal entries in `/lutin/models.local.json` during updates.
- Add **Reload model catalog** and **Update model catalog** to the START command menu.
- Download a compact catalog generated from models.dev and verified transport routes.
- Validate downloads before FAT-safe replacement. Retain the previous catalog on failure.
- Keep queued requests pending when their selected model disappears.
- Paginate model selection and configure reasoning effort per model.
- Package SD files with writable permissions.

## Downloads and upgrade

- `lutin-v0.5.0.nds`: copy to `/roms/nds/lutin.nds`.
- `lutin-v0.5.0-sd.zip`: ROM, model catalog, certificates, configuration, examples, and instructions.
- `SHA256SUMS`: checksums for both downloads.

**When upgrading from v0.4.0, install both the ROM and `/lutin/models.json` from the SD ZIP.**
Keep your existing configuration, provider keys, projects, and sessions.
The ROM no longer includes a model list. Inference requires a valid SD catalog.
Use `models.local.json` for personal changes that must survive catalog updates.

## Verification

Local and GitHub checks cover catalog validation, personal entries, FAT recovery, removed-model queues, and emulator reloading.
The host harness successfully downloaded the published catalog over HTTPS without a provider key and preserved personal entries.
The daily catalog-generation workflow passed its manual run.
Physical-console catalog downloads remain unverified.

See the [catalog documentation](https://github.com/sachahjkl/lutin/blob/v0.5.0/docs/model-catalog.md) for the JSON format and commands.
