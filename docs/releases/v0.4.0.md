# Lutin v0.4.0

Lutin is an AI coding agent for Nintendo DSi.

## Changes

- Discover projects on SD, create them on demand, and select them through paginated lists.
- Remove the eight-project menu limit and the 99-project storage restriction.
- Generate editable Lua assets through the existing versioned file tools.
- Draw palette sprites with transparency, scaling, horizontal flipping, and animation frames.
- Play synthesized music and effects through three square-wave voices and one noise voice.
- Load project assets with `ds.load_asset` during startup or initialization.
- Use named button masks such as `ds.A` and `ds.LEFT` in Lua programs.
- Include an animated sprite and audio example in the SD kit.

## Downloads

- `lutin-v0.4.0.nds`: copy to `/roms/nds/lutin.nds` on the SD card.
- `lutin-v0.4.0-sd.zip`: ROM, CA bundle, configuration, example assets, and instructions.
- `SHA256SUMS`: SHA-256 checksums for both downloads.

For an update, replace the ROM. Keep your configuration, provider keys, projects, and sessions.
The bundled example uses `main.lua`, `hero.lua`, and `sounds.lua` together.
Copy these files into a new project directory to preserve existing creations.

## Verification

Host tests cover project discovery, pagination, sprite rendering, asset validation, audio sequencing, and cleanup.
The emulator check loads the media example from SD and creates a project through the menu.
The reproducibility check compares ROM builds with reversed source discovery order.
Physical-console audio output still needs listening verification.
Audio sequencing advances with runtime frames; long native operations can extend a note.

See [asset documentation](https://github.com/sachahjkl/lutin/blob/v0.4.0/docs/assets.md) for formats, APIs, examples, and limits.
