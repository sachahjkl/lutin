# Lutin v0.3.0

Lutin is an AI coding agent for Nintendo DSi. It writes, runs, and edits Lua programs through OpenCode Go.

## Downloads

- `lutin-v0.3.0.nds`: the ROM. Copy it to `/roms/nds/ai-dsi.nds` on your console SD card.
- `lutin-v0.3.0-sd.zip`: ROM, CA bundle, configuration example, starter animation, and instructions for an existing homebrew setup.
- `SHA256SUMS`: SHA-256 checksums for both files.

For an update, replace the ROM. Keep your existing configuration, API key, and project files.
The ZIP contains a starter `main.lua`. Do not overwrite an existing creation with it.

## Included

- OpenCode Go model selection and HTTPS streaming.
- File, patch, execution, and diagnostic tools, plus Lua Code Mode.
- Persistent sessions, Queue, Steer, reset, and deletion.
- SD configuration with validated model and display preferences.
- VBlank button capture that retains short presses during busy main-loop iterations.
- Individual menu-key isolation, so one held key does not block every other game button.
- English documentation, the Lutin logo, an architecture diagram, and an offline presentation recording.

## Changes from development builds

The personal inference endpoint has been removed.
Sessions now store the model name instead of a numeric menu position.
Older numeric-model sessions use the configured default until you select a model again.

## Verification

Host sanitizer tests and melonDS checks cover the runtime, storage, agent, protocols, configuration, and input capture.
The input probe verifies a short press while the consumer is stalled for two seconds.
The user confirmed earlier agent operation on a DSi XL.
The latest input changes still require physical-console validation.
