# Lutin v0.5.3

## Fix

Run DNS lookup outside the interface loop.
The bundled libcurl uses a synchronous resolver, which previously blocked interface input during DNS waits.
The interface now polls a single resolver worker and passes the resolved address to libcurl.
Certificate and hostname verification remain enabled.

- Cancel a catalog request with B while DNS waits.
- Stop an agent request from the START menu while DNS waits.
- Stop waiting after the 60-second DNS deadline.
- Discard results from cancelled or timed-out requests.
- Show the DNS stage instead of a stale Wi-Fi connection message.

A cancelled lookup finishes in the worker before another lookup starts.
Until then, a new request reports that the DNS worker is unavailable.
This prevents concurrent lookups and keeps worker memory bounded.

## Verification

Host checks cover pending DNS, cancellation, timeout, failure, successful address resolution, and request reuse.
The emulator regression stalls DNS in the production network path and checks cancellation and menu input before DNS returns.
It also checks isolation of late results and retry after the worker finishes.
The emulator injects Wi-Fi association and DNS results; it does not verify external network traffic.

The reported receive failure remains unconfirmed on hardware.
This change does not make TLS computation or filesystem operations preemptible.

## Upgrade

From v0.5.0 or later, replace the ROM and retain your SD data.
From an earlier version, also install `/lutin/models.json` from the SD ZIP.
