Latest release & SD kit ↓Installation guide ↗

Choose the SD ZIP for the ROM, model catalog, certificates, and starter projects. Release downloads include SHA-256 checksums.

  1. Prepare a FAT32 SD card and a DSi homebrew launcher.
  2. Copy the release files to your SD card. Keep existing projects and settings.
  3. Add your OpenCode Go key and configure DSi Wi-Fi.
  4. Launch Lutin in DSi mode. Ask it to make something.

Requires your own OpenCode Go account and API key. Tested by the user on DSi XL. Start with the DSi CFW Guide if you need a launcher.
