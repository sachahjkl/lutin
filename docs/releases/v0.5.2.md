# Lutin v0.5.2

## Fix

Catalog updates now use a dedicated screen with the keyboard hidden.
The screen shows network progress and the B button to cancel.
The first network tick starts after the update screen reaches the display.
The result stays visible until you open the START menu.

This fixes the catalog update display transition.
The reported connection failure and physical-console freeze remain under investigation.

## Upgrade

From v0.5.0 or v0.5.1, replace the ROM and retain your SD data.
From an earlier version, also install `/lutin/models.json` from the SD ZIP.
