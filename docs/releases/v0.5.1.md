# Lutin v0.5.1

## Fix

The compact status area displayed only the first 64 characters of an error.
This could hide the cause and elapsed time of a connection failure.

Open **START → Diagnostics** to read the full saved network error on the lower screen.
Use Left/Right to view network, agent, program, or interface diagnostics.
The network status buffer now retains the complete libcurl error buffer.

This release improves error visibility. It does not change connection behavior.

## Downloads

- `lutin-v0.5.1.nds`: copy to `/roms/nds/lutin.nds`.
- `lutin-v0.5.1-sd.zip`: ROM, catalog, configuration, certificates, and examples.
- `SHA256SUMS`: checksums for both downloads.

From v0.5.0, replace the ROM and retain your SD data.
From an earlier version, also install `/lutin/models.json` from the ZIP.
